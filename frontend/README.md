## Backend Connection

The frontend expects a backend API at `http://localhost:8000` by default.
You can change this in the **Settings** tab or by editing `src/App.tsx`.

## Tabs

1. Dashboard - Main overview
2. Input - Daily/weekly data entry
3. Output - Filtered daily output with date range
4. Basic Trends and Insights - Aggregate metrics
5. LLM Insights - LLM-generated insights
6. Settings - Configuration options
